# GAN Design Eval Rubric — «Не попадись!»

Оценщик открывает http://localhost:8765/index.html (мобильный портрет), проходит старт → забег → итог,
делает скриншоты и ставит баллы 0–10 по каждому критерию. Итог = взвешенная сумма.

**Порог прохождения: 8.0**

### Design Quality (вес 0.35)
Композиция, иерархия, цвет (сберовский бренд), типографика, читаемость для ребёнка 6+,
единство стиля на всех экранах, контраст ≥ 4.5:1.

### Originality (вес 0.30)
Насколько «вкусно» и небанально: глубина/перспектива дороги, характер героя, приземление карточек,
celebration-моменты. Хочется ли ребёнку показать это другим (виральность).

### Craft (вес 0.25)
Плавность 60 fps, аккуратность анимаций, отсутствие дёрганий/наложений/обрезанного текста,
корректный адаптив 360–430pt, `prefers-reduced-motion`.

### Functionality (вес 0.10)
Механика цела: 3 дорожки-действия, карточка едет за героем, очки/жизни/комбо, экран итога с разбором,
ноль ошибок в консоли, пакет ≤ 5 МБ, ноль внешних запросов.

## Жёсткие провалы (score = 0 вне зависимости от остального)
- Любая внешняя зависимость/CDN/шрифт/сетевой запрос.
- Сломанная механика или ошибки в консоли.
- Обучение превратилось в «угадай цвет» (карточки стали цветными по типу).

## Формат вывода оценщика
Для каждого критерия: балл + 1–2 конкретных замечания.
В конце: ВЗВЕШЕННЫЙ ИТОГ, вердикт PASS/FAIL, и топ-3 действия для следующей итерации.
