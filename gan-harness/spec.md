# GAN Design Spec — «Не попадись!»

## Что это
Детский HTML5-раннер (обучение антифроду), ages 6+, инклюзивно под СДВГ.
Код: `../game/` · Запущено: http://localhost:8765/index.html

## Цель лупа
Поднять **визуал и game-feel** забега до референс-уровня (Sber Game Lab), НЕ ломая механику и ограничения.

## Жёсткие ограничения (нарушение = провал итерации)
- Только чистые HTML/CSS/JS + Canvas 2D. **Ноль** библиотек/фреймворков/движков/CDN/внешних шрифтов/иконочных пакетов.
- Только системные шрифты. Относительные пути. Без внешних сетевых запросов.
- Пакет игры ≤ 5 МБ (сейчас 48 КБ — держать компактным).
- Портрет, мобайл 360–430pt. 60 fps на слабых устройствах (Android 8).
- `prefers-reduced-motion` уважать (под СДВГ).
- Без дарк-паттернов, без азартных механик, 0+/6+, дружелюбный тон.

## Бренд
- Зелёный Сбера #21A038 → бирюза #00C1A0, золотой акцент #FFC24B.
- Дорожки-действия: 🛑 Отказать (#ff5a5f) / 🔎 Проверить (#3e9bff) / ✅ Можно (#2fd06e).
- Герой — оригинальный персонаж-защитник со щитом (НЕ маскот Сбера).

## Механику сохранить
- 3 дорожки = 3 действия. Ситуация-карточка едет за героем на выбранную дорожку и «приземляется».
- Карточки нейтральные (ребёнок читает текст, а не цвет) — обучение, не «угадай цвет».
- Экраны: старт, забег (HUD/дорога/герой/карточки), итог с разбором ошибок.

## Что улучшать (приоритет)
1. Ощущение скорости и глубины дороги (псевдо-перспектива, параллакс-слои) без потери 60 fps.
2. Полировка героя (анимация бега, реакции) и карточек (появление/приземление).
3. Старт и итог — «вкусные», анимированные, но быстрые (первый экран ≤ 3 сек).
4. Партиклы/juice — ярче, но не перегружая восприятие ребёнка.
