ПРОВЕРКА «НЕ ПОПАДИСЬ!» В WEBVIEW

Проверяется итоговая игра из папки game/, без изменения кода песочницы.
Инструкция сверена с официальными README 18 октября 2026:
Android — https://github.com/vveidi/sber-hse-hackathon-2026-android
iOS — https://github.com/vveidi/sber-hse-hackathon-2026-ios

1. ПОДГОТОВЬ ИГРУ НА КОМПЬЮТЕРЕ
Распакуй итоговый ZIP. В терминале перейди в папку ne-popadis, где находятся
play.html и папка game. Можно написать cd, пробел и перетащить папку из Finder.
Запусти только папку игры:

python3 -m http.server 8769 --bind 0.0.0.0 --directory game

На компьютере проверь http://127.0.0.1:8769/index.html.
Сервер доступен в локальной сети, пока терминал открыт; остановка — Ctrl+C.
Для игры на телефоне подключи телефон и компьютер к одной Wi-Fi сети.
Узнай локальный IP компьютера: на Mac — настройки Wi-Fi, сведения о сети,
IP-адрес. Пример адреса для телефона: http://192.168.1.23:8769/index.html.
192.168.1.23 замени своим IP. 127.0.0.1 на телефоне означает сам телефон.
Текущая демка на 8768 слушает только компьютер; для телефона нужен сервер выше.

2. ANDROID
Скачай официальный репозиторий Android (Code → Download ZIP), распакуй и открой
его в Android Studio. README указывает JDK 21 и compileSdk 36.1.
Дай среде установить зависимости, выбери конфигурацию app и телефон/эмулятор,
нажми Run. Минимальная ОС — Android 8. Для реального телефона подключи его
как устройство разработки по обычной процедуре Android Studio.
На стартовом экране приложения-песочницы введи URL из пункта 1.
Если это Android-эмулятор на том же компьютере:
http://10.0.2.2:8769/index.html
Для физического телефона используй локальный IP компьютера.

3. IPHONE
Скачай официальный репозиторий iOS, открой HackathonSandbox.xcodeproj
в Xcode 26, выбери схему HackathonSandbox и подключённый iPhone/симулятор,
нажми Run. Минимальная ОС — iOS 15. Если Xcode просит настройку подписи,
выполни её в Signing по подсказкам Xcode; код и настройки WebView не меняй.
На стартовом экране песочницы введи http://<IP компьютера>:8769/index.html.
Локальная сеть и HTTP предусмотрены самой официальной песочницей.
Установка инструментов и сборка песочниц могут потребовать интернет;
у самой игры нет внешних сетевых зависимостей.

4. ЧТО ПРОВЕРИТЬ НА УСТРОЙСТВЕ
[ ] Старт без самопроизвольного звука; три удалённые подписи не показываются.
[ ] «Играть» открывает обучение. До закрытия время забега не идёт.
[ ] «Поехали!» и крестик запускают забег без зависания.
[ ] Свайпы вбок меняют дорожку; свайп вверх прыгает.
[ ] Обычная монета даёт +1, X5 над барьером собирается в прыжке и даёт +5.
[ ] Препятствие забирает щит один раз, а персонаж затем восстанавливается.
[ ] На ответ есть 6 секунд; последний вопрос не обрывается финишем.
[ ] Пауза и сворачивание останавливают игровые часы. Возврат не тратит
    накопленное в фоне время и не пропускает сразу несколько событий.
[ ] Поворот не перезагружает игру, кнопки не перекрываются системной панелью.
[ ] Проигрыш и ручное завершение дают обычный итог без поздравления.
[ ] Дожить до 4 активных минут: появится «Поздравляем! Ты прошёл все испытания!».
    Время проверяй секундомером, вычитая паузы. Ожидание в обучении не считать.
[ ] Итог прокручивается; доступны сундуки и кнопка «Начать заново».
[ ] Повтор сбрасывает счётчики. Выход/повторное открытие не сохраняет монеты.
[ ] После загрузки отключение внешнего интернета не ломает текущую игру.
    Для загрузки с ноутбука нужно сохранить локальное Wi-Fi соединение.

5. ЛОГ СОБЫТИЙ ПЕСОЧНИЦЫ
Открой лог кнопкой справа сверху в нативной панели приложения.
FINISH_EVENT — при каждом финале. params.result: completed / lost / stopped.
COMPLETED_EVENT — только после 4 минут с оставшимся щитом, один раз за
открытие экрана. Повторная победа без закрытия WebView не должна слать его снова.
CLOSE_EVENT — при «Выйти из игры».
VIBRATION_EVENT — во время игровых действий.
SHARING_EVENT игра не вызывает, потому что кнопка шеринга удалена.
Не должно быть ошибок загрузки, неизвестных типов, заблокированных переходов
или предупреждений о повторном COMPLETED_EVENT.
Сохрани лог и короткое видео; запиши модель телефона, ОС и версию песочницы.

6. ЕСЛИ НЕ ОТКРЫВАЕТСЯ
Проверь, что сервер запущен в папке ne-popadis, на компьютере адрес работает,
телефон в той же сети и использует IP компьютера. Гостевая Wi-Fi сеть иногда
изолирует устройства. Если macOS показывает запрос для Python, разреши
подключения для этого локального теста. Если страница не грузится, лог песочницы помогает отличить HTTP-ошибку от
ошибки игры. Для диагностики Android README предлагает chrome://inspect;
iOS 16.4+ — Safari → Разработка на Mac.

Safari/Chrome на телефоне полезны для первичной проверки, но не заменяют
этот запуск в нативном Android WebView / WKWebView. В данной сборке выполнены
браузерные и автоматические проверки; нативное устройство ещё не проверялось.
