# 🛡️ Не попадись!

HTML5-игра для детей **6+** про безопасность: учит на лету распознавать приёмы мошенников.
Хакатон Sber «Создаём эмоции» · **Track B (Игры)**.

> **Цель обучения:** после игры ребёнок на лету распознаёт типичные приёмы обмана — давление и срочность, выманивание кода из СМС и пароля, «слишком хороший» приз, поддельные ссылки — и выбирает безопасное действие: отказать и позвать взрослого.

---

## 🎮 Что это

Динамичный раннер в духе Subway Surfers, спроектированный **инклюзивно под детей с СДВГ**: короткие забеги, мгновенный рестарт, один фокус внимания, мягкий провал без фрустрации.

Герой бежит по трём дорожкам, каждая — это **действие**:

| Дорожка | Действие | Когда выбирать |
|---|---|---|
| 🛑 Отказать | отказать / положить трубку | код, пароль, «срочно переведи», фейк-приз |
| 🔎 Проверить | спросить взрослого / открыть приложение | странная ссылка, «банк» в чате |
| ✅ Можно | всё в порядке | мама, друг, уведомление в приложении |

Навстречу летит **ситуация** (сообщение/звонок/приз). Ребёнок уводит героя в дорожку с правильной реакцией **до** столкновения. Ошибся — короткая подсказка «почему», и бег продолжается. На финише — звёздный рейтинг и разбор ошибок.

**Почему это обучение, а не викторина:** один и тот же приём прилетает в десятках формулировок → ребёнок учится узнавать паттерн, а не зубрит карточку. Каждое решение = реальный навык.

## 🚀 Как запустить

Игра — набор статических файлов, работает в любом современном браузере и в WebView.

```bash
# из папки game/ поднять любой статический сервер, например:
cd game
python3 -m http.server 8765
# открыть http://localhost:8765/index.html
```

> ⚠️ Нужен именно http-сервер (не `file://`) — иначе браузер не загрузит `content.json` через `fetch` (предусмотрен фолбэк, но контент будет урезан).

**Управление:** свайп влево/вправо, тап по стороне экрана, или стрелки ← → (на десктопе).

## 🧩 Управление контентом без релиза

Все ситуации, тексты, объяснения и параметры сложности — в [`game/content.json`](game/content.json).
Банк может добавлять новые схемы мошенничества, сезонный контент, крутить сложность — **без обновления приложения** (через CMS-ключ / статический JSON).

```json
{
  "icon": "🔢",
  "text": "Назови код из СМС",
  "answer": "refuse",
  "why": "Код из СМС — секрет. Его нельзя сообщать никому, даже «банку»."
}
```

## 🎁 Сундук в конце забега

За каждый забег выдаётся один сундук по числу заработанных монет. Открой его на экране итогов — внутри одна оригинальная карманная зверушка.

| Монеты за забег | Сундук | Шансы редкости |
|---|---|---|
| 0–9 | Деревянный | Необычная — 90%, редкая — 10% |
| 10–24 | Серебряный | Редкая — 75%, суперредкая — 25% |
| 25+ | Золотой | Суперредкая — 90%, мегаредкая — 10% |

Всего 16 зверушек — по четыре в каждой редкости, с равным шансом внутри неё:

- Необычные: Листик, Каплик, Монетик, Планюша.
- Редкие: Искролис, Лунокот, Сравныш, Паролик.
- Суперредкие: Грозокрыл, Кристалуп, Резервик, Чекофин.
- Мегаредкие: Солнегриф, Звездорю, Феникаш, Щиторн.

У каждой зверушки свой навык финансовой грамотности и короткий совет: накопления, расходы, план покупок, безопасность и помощь взрослых. При открытии сундука лента карточек быстро прокручивается и плавно замедляется за 3,8 секунды. Выбранная зверушка останавливается точно под центральной стрелкой, подсвечивается, затем появляется её карточка с советом. Результат определяется до анимации по указанным шансам; в ленте видны только зверушки доступных для этого сундука редкостей. При `prefers-reduced-motion` награда появляется сразу без прокрутки.

Пороги, шансы, описания и встроенные SVG-рисунки находятся в `game/js/rewards.js`. Повторно открыть сундук за тот же забег нельзя; при новом забеге награда сбрасывается. Коллекция между забегами не сохраняется.

## 🔌 Интеграция с приложением

Страница общается с приложением через стандартный `window.postMessage` (канал односторонний, без доступа к данным/платежам):

| Событие | Когда |
|---|---|
| `VIBRATION_EVENT` | верная реакция / сбор монеты |
| `COMPLETED_EVENT` | один раз при первом завершённом забеге (прогресс курса) |
| `FINISH_EVENT` | завершение забега |
| `SHARING_EVENT` | кнопка «Поделиться» |
| `CLOSE_EVENT` | выход |

Звук **не автоплей**, есть тумблер.

## ✅ Соответствие ограничениям Track B

- **Чистые HTML/CSS/JS + Canvas 2D** — ноль библиотек, фреймворков, движков, CDN, внешних шрифтов, трекеров, iframe
- **Только системные шрифты**, относительные пути, без внешних сетевых запросов
- **Пакет < 100 КБ** (бюджет ТЗ — 5 МБ)
- Рассчитано на **каждый запуск с нуля** (WebView чистит localStorage/кэш)
- Портрет, 360–430pt, цель **60 fps** (пулинг объектов, кэш спрайтов)
- `prefers-reduced-motion` уважается (инклюзивно под СДВГ)
- 0+/6+, ФЗ-436, без дарк-паттернов и азартных механик, дружелюбный тон
