# Не попадись!

HTML5-раннер для детей 6+ о безопасности и разумных покупках. Основа — ветка `updated-game` репозитория [OfficeKlerk/ne-popadis](https://github.com/OfficeKlerk/ne-popadis/tree/updated-game), версия `656c400af4d3f57f5eb43e20e1c1c5cc3f4c9d1f`. Изменения подготовлены локально 18 октября 2026.

## Запуск

Распакуйте архив и откройте **play.html в браузере**. Внутри находятся все стили, скрипты, данные и рисунки. Интернет, сервер и установка зависимостей для игры не нужны.

Вариант для локального сервера и WebView — папка `game/`, точка входа `index.html`. При необходимости запуска через localhost:

```sh
cd game
python3 -m http.server 8766 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8766/index.html`. Каталог всех карточек — `events-preview.html` рядом с игрой. Python требуется только для этого способа запуска или пересборки.

## Изменения этой версии

- Убраны три подписи: инструкция на стартовом экране, строка «Нажми на ответ · 6 секунд» в обучении и примечание про сброс монет/зверушек на финале. Механика сброса сохранена.
- Забег ограничен **4 минутами активного времени**. Обучение, пауза и свёрнутая вкладка не расходуют лимит. При достижении 240 секунд с оставшимся щитом появляется плашка «Поздравляем! Ты прошёл все испытания!». Ранний проигрыш и ручное завершение показывают обычный итог.
- Новая ситуация не появляется, если до финиша осталось меньше шести секунд с небольшим запасом на первый кадр. Каждый показанный вопрос получает полное время ответа.

- Обычные дорожные монеты увеличены на 20%; размер монеты X5 сохранён.
- Кнопка «Играть» сначала открывает короткое обучение: обход ящиков, прыжок и выбор ответа. «Поехали!», крестик справа сверху и Esc начинают забег. До этого игра не идёт. При перезапуске с финала подсказка не повторяется. На экране 320×568 всё помещается; режим уменьшения анимации поддерживается.

- К 19 прежним ситуациям добавлены все 22 новых: теперь **41 ситуация** для выбора ответа. Запись монеты осталась отдельным элементом каталога; она не показывается как вопрос. Старые тексты и ответы сохранены.
- Покупки получили сцену с пакетом и качающимся ценником. Остальные события используют подходящие сцены звонка, переписки, аккаунта, подарка, карты, сайта или перевода. Полный текст показывается сразу.
- Цветные стрелки-шевроны на поверхности дороги убраны. Разделители дорожек и обозначения типов препятствий сохранены.
- Над низкими барьерами вместо дуги висит **одна большая монета X5**. Она даёт пять монет и собирается только в прыжке. Надпись остаётся читаемой при вращении; при подборе появляются +5 и анимация полёта в счётчик. Обычные монеты по-прежнему дают одну монету.
- Препятствий примерно в **1,5 раза больше**: 11 / 17 / 20 вместо 7 / 11 / 13 за десятисекундный отрезок. В обычных рядах заняты две дорожки; монеты подсказывают свободную. В обязательных рядах стоят **два высоких ящика и один низкий барьер** — его нужно перепрыгнуть. Обязательных прыжков 1 / 3 / 4 соответственно; между ними есть обычный ряд для приземления. Первый обязательный прыжок в начале игры — после двух обычных рядов.
- На решение всегда **6 секунд активного времени с первого кадра сообщения**, независимо от метров и скорости. Пауза останавливает таймер. Отсчёт использует время кадров, поэтому падение fps не растягивает шесть секунд вслед за физикой движения.
- Сохранены изменения исходной ветки: эффекты верного/неверного ответа, разбор ошибок на финале, защита от нулевых размеров игрового поля.
- Сохранены автономная загрузка полного каталога, относительные пути и единый файл для локальной игры.

## Управление

← / → или A / D — смена дорожки. ↑ / W / пробел — прыжок. На телефоне — свайпы влево, вправо, вверх. При событии можно нажать кнопку нужного ответа. Esc / P открывает паузу. В меню доступны продолжение, завершение забега и выход.

Низкий барьер можно перепрыгнуть. Высокий ящик перепрыгнуть нельзя. Скорость бега растёт, но время ответа остаётся постоянным. Препятствия и монеты убираются перед сообщением; объяснение ошибки не накладывается на следующую ситуацию.

## Награды и состояние

Три сундука стоят 150 / 450 / 900 монет. Вероятности и 16 зверушек сохранены из исходной ветки:

| Сундук | Вероятности редкости |
|---|---|
| Деревянный | 90% необычная, 10% редкая |
| Серебряный | 75% редкая, 25% суперредкая |
| Золотой | 90% суперредкая, 10% мегаредкая |

В каждой редкости четыре зверушки с равным шансом. Награда определяется один раз при покупке; прокрутка её визуализирует. Повторное списание заблокировано. Монеты и зверушки действуют только до нового забега/выхода/перезагрузки. Реальных платежей, бэкенда и постоянного хранилища нет. Звуки по умолчанию выключены; озвучки нет.

## Редактирование

- `game/content.json` — ситуации, ответы и объяснения; `visual` выбирает предметную сцену.
- `game/js/game.js` — цикл игры, отрисовка, шесть секунд выбора, ввод и эффекты.
- `game/js/runner.js` — генерация рядов, обязательные прыжки, бонусы X5, сбор монет и столкновения.
- `game/js/events.js`, `game/events.css` — оформление событий.
- `game/js/city.js` — город и жители.
- `game/js/rewards.js`, `game/js/reward-shop.js`, `game/rewards.css` — награды и магазин.
- `game/js/platform.js` — блокировка фона модальных окон в разных браузерах.

После изменения исходников выполните из корня:

```sh
python3 scripts/build.py
```

Это обновит `game/js/content.js` из JSON и пересоберёт `play.html`. Сгенерированные файлы не нужно редактировать вручную. Для размещения переносите всю папку `game/`; для автономной игры достаточно `play.html`.

## Проверки

```sh
node tests/runner.cjs
node tests/game-flow.cjs
REDUCED_MOTION=1 node tests/game-flow.cjs
node tests/events.cjs
node tests/city.cjs
node tests/rewards.cjs
node tests/reward-shop.cjs
node tests/offline.cjs
```

Node.js нужен только для тестов. Проверены 1200 вариантов дороги при 20/30/60/144 fps, сбор одной монеты X5 и начисление пяти монет за прыжок, обязательные прыжки, плавная смена дорожек на ширине 320 px, отсутствие двойного подбора. Таймер проверен отдельно при 10/20/60/144 fps: решение не завершается раньше шести секунд и срабатывает на кадре истечения срока. Проверены перезапуск, пауза, потеря щита, сундуки, полный каталог и обе сборки без сетевых API. Лимит 240 секунд и успешный/неуспешный финал проверены при 10/30/144 fps; последняя карточка не обрывается.

Интерфейс и монета X5 осмотрены в браузере через localhost, в том числе при размере поля 320×568. Карточки ранее проверены на том же размере. Автотесты — проверки логики, а не измерения fps на телефоне. Найдены официальные песочницы Android и iOS; их контракты сверены, но нативный запуск, приём сообщений и загрузка за 3 секунды не проверены: локально нет установленного Xcode/симулятора и доступного Android SDK. Подробный аудит собранного архива и ссылки — в SBER-CHECK.txt. Прямое открытие file:// в рамках этой проверки не выполнялось; единый файл проверен статически и запуском его кода в изолированном тестовом окружении.

## Мост приложения

`window.postMessage({type, params}, "*")`: FINISH_EVENT при каждом финале, COMPLETED_EVENT один раз за загрузку после первого успешного четырёхминутного финиша, CLOSE_EVENT при выходе, VIBRATION_EVENT по игровым действиям. Метод SHARING_EVENT сохранён, кнопки шеринга нет. Ранний проигрыш и ручной финал не отправляют COMPLETED. Условие успеха — дойти до четырёхминутного финиша хотя бы с одним щитом; это не означает безошибочное прохождение всего каталога.

Полное соответствие всем условиям хакатона не заявляется: успешный забег длится 4 минуты, но при раннем проигрыше сессия короче 3 минут, проверка на устройствах и детский плейтест ещё нужны. Сохранённые требования находятся в BRIEF.md, первоначальный дизайн — в GDD.md.

Учебная цель: после игры ребёнок различает просьбы раскрыть секретные данные и ситуации, которые нужно проверить со взрослым. Наблюдаемое действие — выбор безопасной дорожки в новой ситуации; устойчивость навыка требует детского плейтеста.

Пошаговый запуск на телефоне и проверка нативных событий — WEBVIEW-TEST.txt.
